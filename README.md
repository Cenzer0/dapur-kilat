Dapur Kilat is a fast-paced Indonesian warung cooking game: orders land on the board, you chop on the talenan, fry on the kompor and plate each dish before its timer runs out. Six original dishes, a growing rush, combos and three hearts.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080 in desktop Chrome. Click ingredients (or press 1–7), C to chop, Space to serve, P to pause. No build step, no network requests — every file the game loads lives under `game/`.
